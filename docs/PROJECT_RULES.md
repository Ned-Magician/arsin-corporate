## Rule 9

Capitalize the File names = Hero.tsx
Component names = export function Hero() {}
| Type | When to Use | Example |
|------|-------------|---------|
| `feat:` | New feature | `feat: add user login` |
| `fix:` | Bug fix | `fix: resolve 404 error` |
| `docs:` | Documentation changes | `docs: update installation guide` |
| `style:` | Code style (formatting, no logic change) | `style: format with prettier` |
| `refactor:` | Code restructuring (no new features or fixes) | `refactor: simplify API calls` |
| `test:` | Adding or updating tests | `test: add unit tests for auth` |
| `chore:` | Maintenance tasks | `chore: update dependencies` |
| `perf:` | Performance improvements | `perf: lazy load images` |
| `ci:` | CI configuration changes | `ci: update GitHub Actions` |
